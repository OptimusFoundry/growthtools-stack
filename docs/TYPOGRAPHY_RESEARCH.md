## 3. Font Pairing Rules

### Core Principles

| Principle | Description | Example |
|---|---|---|
| **Contrast** | Pair fonts that differ in style (serif + sans-serif) to create visual interest | Playfair Display (serif headline) + Inter (sans body) |
| **Concordance** | Pair fonts from the same superfamily or with shared proportions for harmony | Roboto + Roboto Slab, Source Sans 3 + Source Serif 4 |
| **Conflict** | AVOID fonts that are similar but not identical — they create unease | Montserrat + Poppins (too similar, no contrast) |

### The Two-Font Rule for Video

**Use a maximum of 2 fonts per video.** In rare cases, 3 fonts work if the third is an accent (e.g., monospace for a data callout). Using 4+ fonts creates visual chaos.

- **Font 1 — Headline/Hero:** Display, serif, or bold sans. Used for the main message.
- **Font 2 — Body/Subtitle:** Clean, readable sans-serif. Used for supporting text, subtitles, CTAs.
- **Font 3 (optional) — Accent:** Monospace, script, or decorative. Used sparingly for one element (price, date, annotation).

### Hierarchy Through Typography

| Level | Role | Typical Weight | Typical Scale (relative to body) | Example |
|---|---|---|---|---|
| **H1 — Headline** | Primary message, hook text | 700–900 (Bold/Black) | 2.5x–3x body | "50% OFF EVERYTHING" |
| **H2 — Subhead** | Supporting statement, qualifier | 500–700 (Medium/Bold) | 1.5x–2x body | "This weekend only" |
| **Body** | Description, detail text | 400–500 (Regular/Medium) | 1x (baseline) | "Free shipping on orders over $50" |
| **Caption** | Fine print, disclaimers, timestamps | 400 (Regular) | 0.75x–0.85x body | "Terms apply. Ends Sunday." |
| **CTA** | Button text, action text | 600–700 (SemiBold/Bold) | 1.1x–1.3x body | "SHOP NOW" |

- Use bold, condensed fonts: **Oswald**, **Bebas Neue**, **Anton**

- Font size: large enough to read at 120x68px thumbnail preview
- High contrast: white text with dark stroke, or dark text with light stroke
- 3px+ stroke/outline mandatory for readability at small sizes
- ALL-CAPS for maximum scan speed

| **Body Text** | 36–44px | 32–40px | 28–36px | 32–42px |
| **Caption/Fine Print** | 28–32px | 24–30px | 22–28px | 26–32px |
| **CTA Button Text** | 40–56px | 36–48px | 32–44px | 36–48px |

### Minimum Readable Sizes (below these, text becomes illegible on mobile)

| Aspect Ratio | Absolute Minimum | Comfortable Minimum |
|---|---|---|
| 9:16 mobile | 28px | 36px |
| 1:1 feed | 24px | 32px |
| 16:9 landscape | 22px | 28px |

### Font Weight Guidelines for Video

| Weight Range | Name | Video Suitability | Notes |
|---|---|---|---|
| 100–200 | Thin/ExtraLight | **Poor** — avoid in video | Disappears on small screens, illegible during motion, lost on busy backgrounds |
| 300 | Light | **Conditional** — large display sizes only | Works only at 80px+ on clean backgrounds for luxury/minimal aesthetic |
| 400 | Regular | **Good** — body text, subtitles | Standard readable weight for supporting text |
| 500 | Medium | **Excellent** — versatile | Best default for body in video; slightly bolder than regular improves motion readability |
| 600 | SemiBold | **Excellent** — subheads, CTAs | Sweet spot: bold enough to anchor without dominating |
| 700 | Bold | **Excellent** — headlines | Primary headline weight, strong screen presence |
| 800 | ExtraBold | **Good** — impact headlines | Use for short phrases (1-4 words), overpowers longer text |
| 900 | Black | **Conditional** — max 3 words | Maximum visual weight; impactful but can feel oppressive at scale |

### Letter-Spacing (Tracking) for Video

| Context | Letter-Spacing | Why |
|---|---|---|
| ALL-CAPS headlines | +2% to +5% (0.02em–0.05em) | Caps need breathing room; tightly tracked caps feel cramped |
| Mixed-case headlines | 0% to +1% (0em–0.01em) | Default tracking is usually fine for mixed case |
| Body / subtitle text | 0% to +1% | Keep natural; over-tracking body text reduces readability |
| Monospace text | 0% | Already evenly spaced by design |
| Condensed fonts | +1% to +3% | Condensed letterforms benefit from slight opening |

### Line-Height for Video Text

| Text Type | Line-Height | Rationale |
|---|---|---|
| Single-line headline | 1.0–1.1 | Tight: headline should feel like one visual block |
| Multi-line headline | 1.1–1.25 | Slight breathing room to avoid line collision |
| Body text / subtitle | 1.4–1.6 | Standard readability spacing |
| Caption / fine print | 1.3–1.5 | Smaller text needs proportionally more leading |
| CTA button text | 1.0 | Single line, vertically centered in button |

### Characters Per Line for Video

| Format | Max Characters (Headline) | Max Characters (Body) | Max Words Per Frame |
|---|---|---|---|
| 9:16 vertical | 15–20 chars | 30–35 chars | 8–12 words |
| 1:1 square | 20–25 chars | 35–45 chars | 10–15 words |
| 16:9 landscape | 30–40 chars | 50–60 chars | 12–20 words |

## 7. Font + Animation Pairing

### Animation Types Reference

| Animation | Description | Motion Feel |
|---|---|---|
| **fadeIn** | Opacity 0 to 1 | Subtle, elegant, smooth |
| **slideUp** | Translates from below + fades | Professional, structured |
| **slideDown** | Translates from above + fades | Descending, revealing |
| **slideLeft/Right** | Horizontal translate + fade | Directional, flowing |
| **scaleIn** | Scales from 0% to 100% + fades | Dramatic, impactful |
| **popIn** | Scales from 80% to 105% to 100% with spring | Energetic, bouncy, fun |
| **slamDown** | Fast translateY with bounce + slight screen shake | Aggressive, urgent |
| **typewriter** | Characters appear one by one with cursor | Precise, technical, narrative |
| **wipeReveal** | Mask reveals text left-to-right or top-to-bottom | Editorial, cinematic |
| **characterCascade** | Per-character stagger with scale + fade | Premium, Apple-style |
| **blurFocus** | blur(40px) to blur(0) | Cinematic, mysterious |
| **bounceIn** | Scale + translate with elastic overshoot | Playful, energetic |
| **rotateIn** | Rotation + scale + fade | Dynamic, attention-grabbing |
| **glitchReveal** | RGB split + position jitter + opacity | Edgy, tech, cyberpunk |

### Font Style to Animation Mapping

| Font Style | Best Animations | Good Animations | Avoid |
|---|---|---|---|
| **Bold Sans-Serif** (Bebas Neue, Anton, Archivo Black) | slamDown, scaleIn, popIn, slideUp | wipeReveal, fadeIn | typewriter, characterCascade (too slow for bold energy) |
| **Elegant Serif** (Playfair Display, Cormorant Garamond) | fadeIn, wipeReveal, characterCascade, blurFocus | slideUp, scaleIn | slamDown, popIn, bounceIn (too aggressive for elegance) |
| **Clean Sans-Serif** (Inter, DM Sans, Roboto) | slideUp, fadeIn, wipeReveal | scaleIn, popIn | glitchReveal, slamDown (mismatched energy) |
| **Geometric Sans** (Montserrat, Poppins, Sora) | slideUp, popIn, scaleIn, fadeIn | bounceIn, wipeReveal | glitchReveal (wrong aesthetic) |
| **Condensed Sans** (Oswald, Barlow Condensed) | slideUp, slamDown, wipeReveal | fadeIn, scaleIn | bounceIn (condensed + bounce looks compressed) |
| **Script / Handwritten** (Dancing Script, Caveat, Pacifico) | wipeReveal, fadeIn, characterCascade | slideUp | slamDown, glitchReveal, popIn (destroys elegance) |
| **Monospace** (Space Mono, Fira Code, Roboto Mono) | typewriter, fadeIn, glitchReveal | slideUp, wipeReveal | bounceIn, scaleIn (too organic for mono precision) |
| **Display / Decorative** (Righteous, Pacifico) | scaleIn, popIn, rotateIn, bounceIn | fadeIn, slideUp | typewriter (decorative + typewriter looks odd) |
| **Slab Serif** (Roboto Slab, Arvo) | slideUp, fadeIn, wipeReveal | slamDown, scaleIn | characterCascade (slab shapes feel heavy per-character) |
| **Rounded Sans** (Nunito, Quicksand) | popIn, bounceIn, fadeIn, slideUp | scaleIn | slamDown, glitchReveal (too harsh for soft shapes) |

### Animation Speed by Font Weight

| Font Weight | Recommended Duration | Easing | Notes |
|---|---|---|---|
| 100–300 (Thin/Light) | 500–800ms | Gentle ease-out | Light fonts need slow reveals to be noticed |
| 400–500 (Regular/Medium) | 350–600ms | Standard ease-out | Balanced timing |
| 600–700 (SemiBold/Bold) | 250–500ms | Snappy ease-out or spring | Bold fonts can handle fast entrances |
| 800–900 (ExtraBold/Black) | 150–350ms | Hard ease-out, spring with damping | Heavy fonts suit aggressive, fast entrances |

## 8. Accessibility & Readability

### Contrast Ratios for Video Text

| Context | Minimum Ratio | Recommended Ratio | Standard |
|---|---|---|---|
| Body text on solid background | 4.5:1 | 7:1 | WCAG AA / AAA |
| Large text (18pt+ or 14pt bold+) on solid | 3:1 | 4.5:1 | WCAG AA for large text |
| Text on image/video background | 4.5:1 with treatment | 7:1 with treatment | Requires background treatment |
| CTA button text | 4.5:1 | 7:1 | Critical for conversion |

### Techniques for Text on Busy Backgrounds

| Technique | Implementation | When to Use | Impact on Readability |
|---|---|---|---|
| **Text Stroke/Outline** | 2–4px contrasting stroke around text | All text on photo/video backgrounds | High — creates consistent edge contrast around every letter |
| **Drop Shadow** | `2px 2px 4px rgba(0,0,0,0.7)` or equivalent | Subtle readability boost, lighter backgrounds | Medium — adds depth separation |
| **Background Box** | Semi-transparent rectangle behind text (rgba 0.5–0.8 opacity) | Long body text on busy backgrounds | Very high — guaranteed readability |
| **Gradient Overlay** | Dark gradient at top/bottom of frame where text lives | Cinematic style, full-bleed imagery | High — subtle but effective |
| **Full-Width Text Bar** | Opaque strip across frame width, text centered | News/caption style, TikTok subtitles | Very high — professional, TV-native |
| **Frosted Glass / Blur** | Background blur behind text region | Modern/tech aesthetic | High — adds depth effect |
| **Dark Vignette** | Radial gradient darkening edges where text sits | Cinematic, photo-centric videos | Medium — natural-looking treatment |

### Recommended Stroke/Outline Settings

| Text Size | Stroke Width | Color | Notes |
|---|---|---|---|
| Small (28–36px) | 1.5–2px | Black or dark complementary | Thin stroke prevents letter clogging |
| Medium (40–64px) | 2–3px | Black at 80–100% opacity | Standard readable stroke |
| Large (72–120px) | 3–5px | Black or contrasting brand color | Bold stroke for maximum impact |
| Huge display (120px+) | 4–6px | Variable | Can use colored strokes as design element |

### Fonts That Maintain Legibility During Motion

**Best performers during animation (high legibility in motion):**
- Inter (large x-height, open counters)
- Roboto (natural rhythm, clear forms)
- Montserrat (balanced geometry)
- Poppins (rounded terminals, clear)
- Open Sans (wide apertures)
- Bebas Neue (simple forms, high contrast)
- Oswald (clear condensed forms)

**Poor performers during motion (avoid animating these):**
- Thin weight fonts (100–200) — disappear during fast motion
- Highly decorative scripts — detail lost during motion blur
- Fonts with very tight letter-spacing — merge together in motion
- Low-contrast fonts at small sizes — insufficient differentiation

### Dyslexia-Friendly Considerations

| Guideline | Recommendation |
|---|---|
| **Best Google Fonts** | Lexend (specifically designed for reading ease), Open Sans, Roboto, Poppins |
| **Letter spacing** | Increase by 12%+ over default (0.12em minimum) |
| **Word spacing** | 16%+ over default (0.16em minimum) |
| **Line height** | 1.5x or greater |
| **Text alignment** | Left-aligned preferred; avoid justified text |
| **Minimum size** | 36px+ for video text; never below 28px |
| **Font weight** | 400–600; avoid thin weights (100–300) |
| **Avoid** | ALL-CAPS for body text, italic for long passages, tightly spaced condensed fonts |
